## habitatquest-step4：新增中英双语切换（默认英文）

**需求边界**：界面 + 教学辅助文案切换；英语学习材料（目标句、Pip 的 Why/How 追问、伙伴英文回应、句型支架、学生英文转写）始终保持英文。顶栏与设置抽屉两处入口，默认英文。

**架构决策**
- 不引入 i18n 库、不用 React Context。`src/i18n/index.ts` 用 `useSyncExternalStore` 做零依赖 store，因为 `quota.ts` / `network.ts` / providers / scoring 等非 React 模块也要产出文案。

- API：`getLang/setLang/subscribeLang/t(key,vars)/tr(value,vars)/renderPieces(pieces)/useI18n()`。
- **关键约定：动态文案存 i18n key，不存成品字符串**。`I18nPiece[]`、`ScoreResult.adviceI18n`、`CheckResult.reasonKey/reasonVars`、`PhonemeHint.tipKey`、`RequestLogEntry.noteVars`、`ChatBubble.textI18n` 让练习中途切换语言时已生成的气泡/评分建议/回答评价/日志状态即时重译。
- `Config.language: 'en'|'zh'` 持久化到 `hq4:config`；`src/i18n/index.ts` 在模块加载时读持久化值，避免首屏英文闪烁；切换同步 `document.documentElement.lang` 与 `document.title`。
- 双语展示辅助：`mock/cards.ts` 的 `habitatName()` / `animalName()`；中文动物名仅在 `zh` 显示。
- API 通道 `advice` 按当前界面语言生成（`prompt.adviceRule` / `prompt.adviceLang`），JSON 字段名不变；`refine.ts` 用 API advice 时丢弃 `adviceI18n`（成品文本不重译，已在 README 诚实标注）。

**改造文件**：新增 `src/i18n/`；改 `types.ts` / `storage.ts` / `index.html` / `index.css` / `App.tsx`；全部 12 个 components；`lib/quota.ts` / `network.ts` / `scoring/*`；`providers/*`；`mock/cards.ts` / `partner.ts` / `phonemeHints.ts`；`README.md`。

## 追加修复：语音识别丢转写 + 去掉 Step 4 命名

**用户反馈**：改英文后「识别不了了」——截图显示 `Recognising:this is a arctic fox…`（引擎已听到）但 `Transcript:Didn't catch that`；另要求把界面里的 `Step 4` 换成 `Speaking Practice`。

**根因**（`src/lib/speech.ts`）：旧实现只把 `isFinal` 结果塞进 `finals`，interim 仅用于显示；且 `stop()` 立即快照 `finals` 并置 `stopped=true`，使 `onend` 提前 return。Chrome 在慢速/受限网络下常只给 interim，或在 `stop()` 之后才补发 final —— 两种情况都会把学生说过的话全部丢掉。

**修复**
- 每次 `onresult` 从**完整 `e.results`** 重建转写（finals + 未定稿 interim），实时写入 `pending`；`consumed` 后忽略迟到事件。
- `stop()` 不再冻结/不关闭会话；`RecognitionHandle` 新增 `finish(): Promise<TranscriptResult>`，`Recorder` 在 `MediaRecorder.onstop` 里 `await handle.finish()` 后再生成 take；`Promise.race([onend, 900ms 兜底])` 防卡死。
- 空转写时自动展开「上传 / 输入兜底」并提示 `rec.micEmptyHint`（en/zh 均新增键）。
- 英文前缀补空格：`rec.interim` / `rec.transcript` / `set.keyCurrent` → `'Recognising: '` / `'Transcript: '` / `'Current: '`。
- `rec.lang` 固定 `'en-US'`，**不随界面语言变**（练习材料恒为英文）。

**命名**：新增 `top.brandSuffix`（Speaking Practice / 口语练习）、`top.tagPractice`（Voice Practice / 语音练习）、`report.tag`；删除 `top.tagStep4`。顶栏 h1、左栏徽标、成长报告徽标、index.html 标题、app.title、README、一键启动.bat、脚本与文件头注释全部替换。保留 `package.json` 的 `habitatquest-step4`（内部包名）、`guide.step4`（五步教学里真实的第 4 步）、`hq-*.yml`（历史快照）。

**顺带修**：英文 CTA `① Listen to the English model and start this round` 在 375px 下撑出 2px 横向滚动；`.cta-row .btn-lg { max-width:100%; white-space:normal; text-align:center; line-height:1.3 }` 允许窄屏换行，320/375px 均无横向滚动，1440px 仍单行。

**验证**：模拟 `SpeechRecognition` 四场景通过（仅 interim → 完整转写；stop 后补发 final → 收到，置信度 0.85；abort → 清空；不发 onend → 903ms 兜底）。typecheck + build 通过（1624 modules，dist/index.html 480,675 B 自包含）。默认 EN 顶栏 `HabitatQuest · Speaking Practice`、页面无 `Step 4`；切 ZH 为 `HabitatQuest · 口语练习`；文字兜底全流程回归通过；控制台 0 error / 0 warning。

**注意**：Chrome 同时暴露 `window.SpeechRecognition` 与 `webkitSpeechRecognition`，做 mock 测试时**两个都要覆盖**；只覆盖 webkit 会静默走真实引擎导致测试误判。
